# 戦略を書き直す

今の目標と進め方を、`game_notes/<ゲーム>/strategy.md` に自由な文で書き直す。`<ゲーム>` は advisor への指示で渡されたゲーム名にする。
速い層 (画面を見て、問いごとに型付きの判断を返すモデル) は、このファイルを手がかりに、押した状態にするボタン・短押しするボタン・スティックの向きを選ぶ。

## 書くこと

- 今の目標 (1〜2 文)
- 今の場面で押すべきボタンの方針 (例: 会話が出ている間は A を短押しして送る、フィールドでは左スティックを右に倒して進む)
- 避けるべき操作 (例: メニューが開いている間は B を押し続けない)
- 安全のための制限 (advisor への指示にある安全のための規則を、今の場面に合わせて書く)
  - 通信対戦のソフト、オンラインに接続する機能、ショップでの購入を選ばない
  - HOME メニューでは、試行しているソフト以外を起動しない
  - セーブデータの削除と、本体の設定の変更をしない
  - 迷ったら何も押さない

## 書き方

1. `game_notes/<ゲーム>/strategy.md` と、ほかの 3 ファイル (controls.md・tips.md・progress.md) を読む
2. context.md と画像、操作の記録から、今の戦略が画面の状況に合っているかを確かめる。合わない記述、古くなった記述は消して書き直す
3. 確かめた事実と推測を分けて書く。根拠にした観察の回数と画像のラベルを添える
   - 例: `- 会話が出ている間は A を短押しする (観察 3 回、根拠: 直近 3/5 (0.30 秒前))`
4. ファイルは速い層の要求に毎回そのまま入るため、短く保つ。1500 字以内を目安にし、今の場面に必要なことだけを書く
5. 書き換えてよいのは `game_notes/<ゲーム>/` の 4 ファイルだけ。ほかのファイルは書き換えない
