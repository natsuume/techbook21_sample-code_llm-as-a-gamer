# 目標と戦略を書き直す

今の目標、進行状況、進め方 (戦略) を、`game_notes/<ゲーム>/strategy.md` に書き直す。`<ゲーム>` は advisor への指示で渡されたゲーム名にする。
速い層 (画面を見て、問いごとに型付きの判断を返すモデル) は、このファイルを手がかりに、押した状態にするボタン・短押しするボタン・スティックの向きを選ぶ。

## 書くこと

strategy.md は、次の 3 つの節で書く。

### 1. 目標

- 大目標・中目標・小目標の 3 段階で書く (例: 大目標「ゲームをクリアする」、中目標「1 面をクリアする」、小目標「最初の扉を開ける」)
- 各目標に、状態 (未着手 / 途中 / 達成 / 不成立) を付ける
- 達成か不成立かは、最も細かい段階の目標から判断する
- 小目標が達成されたら、その中目標の次の小目標を立てる
- 中目標のすべての小目標が済んだら、中目標を達成とし、次の中目標と、その最初の小目標を立てる
- 不成立のときは、理由を 1 行書き、代わりの目標を立てる

### 2. 進行状況

- どこまで進んだか (章、ステージ、イベント)
- 今いる場所と、画面の状態 (フィールド、メニュー、会話中など)
- 持ち物、所持金、体力などの、画面で確かめられる値
- 進行状況は今の状態を書く節なので、過ぎた状態の記述は消す

### 3. 戦略

- 今の小目標に向けた進め方
- 押すべきボタンの方針 (例: 会話が出ている間は A を短押しして送る、フィールドでは左スティックを右に倒して進む)
- 避けるべき操作 (例: メニューが開いている間は B を押し続けない)
- 安全のための制限 (advisor への指示にある安全のための規則を、今の場面に合わせて書く)
  - 通信対戦のソフト、オンラインに接続する機能、ショップでの購入を選ばない
  - HOME メニューでは、試行しているソフト以外を起動しない
  - セーブデータの削除と、本体の設定の変更をしない
  - 迷ったら何も押さない

## 書き方

1. `game_notes/<ゲーム>/strategy.md` と、ほかの 3 ファイル (controls.md・tips.md・advice.md) を読む
2. context.md と画像、操作の記録から、今の目標が達成されたか、達成できないと分かったかを判断し、目標の状態を書き直す。続けて、進行状況と戦略が画面の状況に合っているかを確かめ、合わない記述や古くなった記述は消して書き直す
3. 確かめた事実と推測を分けて書く。事実の行には観察の回数と、根拠にした画像のラベルを添える
   - 事実: `- 会話が出ている間は A を短押しする (観察 3 回、根拠: 直近 3/5 (0.30 秒前))`
   - 推測: `- (推測) 次はボス戦になる (観察 1 回)`
4. ファイルは速い層の要求に毎回そのまま入るため、短く保つ。2500 字以内を目安にし、今の場面に必要なことだけを書く
5. 書き換えてよいのは strategy.md だけ。ほかの 3 ファイルは読むだけにする
