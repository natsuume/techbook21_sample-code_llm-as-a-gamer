# 攻略情報を記録する

学んだ攻略情報を、`game_notes/<ゲーム>/tips.md` に書く。`<ゲーム>` は advisor への指示で渡されたゲーム名にする。

## 書くこと

- 敵の特徴 (動き方、弱点、避け方)
- ゲームの仕組み (アイテムの効果、体力の回復、セーブの方法など)
- 注意点 (落ちると戻される場所、取り返しのつかない選択など)
- 同じ失敗を繰り返したときは、その原因と避け方

## 書き方

1. `game_notes/<ゲーム>/tips.md` を読み、今の内容を確かめる
2. context.md と画像から分かったことを足す。古くなった記述や、確かめた結果と違う記述は消して書き直す
3. 確かめた事実と推測を分けて書く。事実の行には観察の回数と、根拠にした画像のラベルを添える
   - 事実: `- 赤い敵は近づくと突進してくる (観察 2 回、根拠: 過去の場面 3/5 (8.20 秒前))`
   - 推測: `- (推測) 突進の後はしばらく止まる (観察 1 回)`
4. ファイルは速い層の要求に毎回そのまま入るため、短く保つ。3000 字以内を目安にし、重要なものから並べる
5. 書き換えてよいのは tips.md だけ。ほかの 3 ファイルは読むだけにする
