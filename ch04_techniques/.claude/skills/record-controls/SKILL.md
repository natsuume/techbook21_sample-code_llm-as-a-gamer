# 操作方法を記録する

試して分かった操作方法を、`game_notes/<ゲーム>/controls.md` に書く。`<ゲーム>` は advisor への指示で渡されたゲーム名にする。

## 書くこと

- ボタンの割り当て (例: A で決定、B で戻る、X でメニュー)
- 会話の送り方、選択肢の選び方
- メニューやマップの開き方と閉じ方
- スティックの動き (移動、カメラ) と、押したままにする操作

## 書き方

1. `game_notes/<ゲーム>/controls.md` を読み、今の内容を確かめる
2. context.md と画像から分かったことを足す。古くなった記述や、確かめた結果と違う記述は消して書き直す
3. 確かめた事実と推測を分けて書く。事実の行には観察の回数と、根拠にした画像のラベルを添える
   - 事実: `- A で会話を送る (観察 3 回、根拠: 直近 2/5 (0.40 秒前))`
   - 推測: `- (推測) ZR で走るかもしれない (観察 1 回)`
4. ファイルは速い層の要求に毎回そのまま入るため、短く保つ。3000 字以内を目安にし、重要なものから並べる
5. 書き換えてよいのは `game_notes/<ゲーム>/` の 4 ファイルだけ。ほかのファイルは書き換えない
