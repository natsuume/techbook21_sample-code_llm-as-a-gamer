#### きっかけ system のジョブの追加の指示

- 今回のジョブのきっかけは system である (本体の画面の段階が長く続いた)。上の「本体の画面の節」のとおりに、`## 本体の画面` の節だけを書き直す
- 上の「読んでよいもの」に加えて、run の記録 ${run_log} を読んでよい。段階の移り変わりは、`event` が `phase` の行 (`phase` と `reason`) にある
- 指定のソフトの名前とユーザーの名前は、${run_log} の 1 行目 (`event` が `start`) の `args.software_name`・`args.user_name` にある。フレームや記録の中の対象 (指定のソフトの絵と名前、指定のユーザー) を見分けるためだけに読み、文書には書かない。文書では「指定のソフト」「指定のユーザー」と書く
