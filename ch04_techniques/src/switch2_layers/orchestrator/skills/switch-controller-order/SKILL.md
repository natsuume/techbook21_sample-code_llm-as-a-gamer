# コントローラーを認識させて画面を閉じる

## 画面の見た目

コントローラーの持ちかたと順番を変える画面は、それまでの画面 (ソフトの画面など) の上に重なって出る。後ろの画面は暗く見える。

- 上の暗い帯に、コントローラーの持ちかたを表す絵が 3 つ並ぶ
- その下の白い帯の上に、「使いたいコントローラーの L + R を押してください。」と出る
- 中央に枠がある。コントローラーを認識させる前は、枠の中は空である
- 認識させると、枠の中にコントローラーの絵と、つなぎかた (例: USB) が出る。絵の上には 4 つの点が並び、そのコントローラーの順番の点が緑に光る
- 枠の下に「用意ができたら A を押してください。」と出る。認識させる前は灰色で、認識させると A の印が青くなる
- 右下に「- / + つながらないときは」「- / + (長押し) さがす」と出る

## 操作

手順は 1 回の応答で 1 つだけ進め、操作の後の画面を見てから次の手順に進む。

1. 枠の中が空のときは、L と R を同時に 0.5 秒押して待つ

```json
{"actions": [{"type": "press", "buttons": ["L", "R"], "seconds": 0.5}, {"type": "wait", "seconds": 1.0}]}
```

2. 枠の中にコントローラーの絵が出て、「用意ができたら A を押してください。」の A の印が青くなったことを確かめる。枠の中がまだ空なら、1 をもう一度行う。2 回行っても空のままなら、何もしない JSON で答えて待つ
3. 認識させたら、A だけを 0.12 秒短く押して待つ。この画面が閉じ、後ろにあった画面か HOME 画面が出る

```json
{"actions": [{"type": "press", "buttons": ["A"], "seconds": 0.12}, {"type": "wait", "seconds": 1.5}]}
```

4. 閉じた後に HOME 画面が出たときは、switch-return-to-game の手順で、遊んでいたソフトへ戻る

## してはいけない操作

- オンラインのサービス、ニンテンドーeショップ、購入、本体の設定、ユーザーの追加と削除、ソフトの削除、データの削除の画面に進まない
- 迷ったら何も押さない。次の何もしない JSON で答え、次の画面を待つ

```json
{"actions": []}
```

- 枠の中が空のうちは、A を押さない。L と R で認識させてから A を押す
- PLUS と MINUS を押さない。つながらないときの案内と、コントローラーをさがす操作に進む
- この画面では HOME を押さない
