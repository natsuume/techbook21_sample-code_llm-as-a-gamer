# ユーザーを選ぶ

## 画面の見た目

ユーザー選択の画面は、HOME 画面でソフトの絵を選んで A を押した後に、HOME 画面の下半分に白い枠で重なって出る。上に見える HOME 画面は暗くなる。

- 枠の左上に「だれがソフトをあそびますか?」と出る
- 枠の中央に、ユーザーのアイコンが横に並ぶ。それぞれのアイコンの下に、ユーザーの名前が出る
- アイコンの並びの右端に、「+」の丸がある。「+」はユーザーの追加に進む
- 選ばれているアイコンは、色の付いた輪で囲まれる。画面が出たときは、左端のユーザーが選ばれている
- 左下にコントローラーの印、右下に「B もどる」「A 決定」が出る (ボタンの名前は丸で囲んで表示される)

## 操作

手順は 1 回の応答で 1 つだけ進め、操作の後の画面を見てから次の手順に進む。ボタンは 0.12 秒だけ短く押し、押した後は画面が変わるまで待つ。

1. 輪で囲まれているのがユーザーのアイコンで、「+」ではないことを確かめる。輪が「+」にあるときは、LEFT を 1 回押して輪をユーザーのアイコンに戻す

```json
{"actions": [{"type": "press", "buttons": ["LEFT"], "seconds": 0.12}, {"type": "wait", "seconds": 0.5}]}
```

2. 初期指示で遊ぶユーザーが指定されていないときは、選ばれているユーザーのまま、A だけを短く押して決定する。画面が暗くなり、ソフトの起動の画面に移る

```json
{"actions": [{"type": "press", "buttons": ["A"], "seconds": 0.12}, {"type": "wait", "seconds": 1.5}]}
```

3. 初期指示で遊ぶユーザーが指定されているときは、アイコンの下の名前を読み、輪が指定のユーザーのアイコンにあるかを確かめる。無いときは、LEFT か RIGHT を 1 回だけ押し、輪が動いたのを見てから、もう一度確かめる。次の例は右へ 1 つ動かす

```json
{"actions": [{"type": "press", "buttons": ["RIGHT"], "seconds": 0.12}, {"type": "wait", "seconds": 0.5}]}
```

4. 輪が指定のユーザーのアイコンにあることを確かめてから、2 と同じ JSON で A だけを短く押して決定する
5. 指定の名前のユーザーが並びに無いときは、ユーザーを選ばずに、何もしない JSON で答えて待つ

## してはいけない操作

- オンラインのサービス、ニンテンドーeショップ、購入、本体の設定、ユーザーの追加と削除、ソフトの削除、データの削除の画面に進まない
- 迷ったら何も押さない。次の何もしない JSON で答え、次の画面を待つ

```json
{"actions": []}
```

- 輪が「+」にあるときに A を押さない。ユーザーの追加に進む
- 決定の前に、輪で囲まれているのがユーザーのアイコンであることを、毎回確かめる。十字キーを押した直後は、輪の位置を見てから A を押す
- 指定のユーザーが並びに無いときに、ユーザーを追加して作らない
- B (もどる) を押さない。ユーザーを選ばずに、この画面を閉じることになる
- A をほかのボタンと同時に押さない。1 つの press の buttons は ["A"] だけにする
