# 本体のダイアログを閉じる

## 画面の見た目

本体のお知らせ・確認のダイアログは、それまでの画面 (HOME 画面やソフトの画面) の上に重なって出る。

- ダイアログの中には、お知らせや確認の文と、1 つ以上のボタンがある
- 文言、ボタンの数と並び、出たときに選ばれているボタンは、ダイアログごとに違う。出たときに選ばれているボタンが、先へ進める側のこともある

HOME 画面の確認のダイアログ「プレイ中のソフトを終了します。」は、次の見た目である。

- 暗くなった HOME 画面の中央に白い枠が出る。枠の左に起動しているソフトの小さな絵、右に「プレイ中のソフトを終了します。」「セーブしていない内容は消えてしまいます。」と出る
- 枠の下に、左に「キャンセル」、右に「終了する」のボタンが並ぶ。選ばれているボタンは、色の付いた枠で囲まれる
- 出たときに選ばれているのは「終了する」で、A を押すと起動しているソフトが終わる

## 操作

手順は 1 回の応答で 1 つだけ進め、操作の後の画面を見てから次の手順に進む。ボタンは 0.12 秒だけ短く押し、押した後は画面が変わるまで待つ。

1. ダイアログの文と、すべてのボタンの文言を読む。どのボタンが選ばれているかも確かめる
2. 「キャンセル」「閉じる」「もどる」のように、何も進めずにダイアログを閉じるボタンがあるときは、B を短く押して閉じる。「プレイ中のソフトを終了します。」も B で閉じる

```json
{"actions": [{"type": "press", "buttons": ["B"], "seconds": 0.12}, {"type": "wait", "seconds": 1.0}]}
```

3. B を押してもダイアログが閉じないときは、閉じるだけのボタンに十字キーで選択を動かす。ただし「プレイ中のソフトを終了します。」が B で閉じないときは、選択を動かさず、何も押さずに待つ。1 回の応答で 1 回だけ押し、枠がそのボタンに移ったのを見てから次を決める。次の例は左へ 1 つ動かす

```json
{"actions": [{"type": "press", "buttons": ["LEFT"], "seconds": 0.12}, {"type": "wait", "seconds": 0.5}]}
```

4. 閉じるだけのボタンが選ばれていることを確かめてから、A だけを短く押して閉じる。閉じるだけのボタン (「OK」など) が 1 つだけのお知らせも、この JSON で閉じる

```json
{"actions": [{"type": "press", "buttons": ["A"], "seconds": 0.12}, {"type": "wait", "seconds": 1.0}]}
```

5. どのボタンが閉じるだけのものか分からないときは、何も押さずに待つ

## してはいけない操作

- オンラインのサービス、ニンテンドーeショップ、購入、本体の設定、ユーザーの追加と削除、ソフトの削除、データの削除の画面に進まない
- 迷ったら何も押さない。次の何もしない JSON で答え、次の画面を待つ

```json
{"actions": []}
```

- 「プレイ中のソフトを終了します。」のダイアログで A を押さない。出たときに選ばれているのは「終了する」で、A を押すと起動しているソフトが終わる。このダイアログは B で閉じる
- 選ばれているボタンを確かめずに A を押さない。出たときに選ばれているボタンが、先へ進める側のことがある
- 次のように先へ進めるボタンを選ばない: ソフトを終了する、オンラインにつなぐ、ニンテンドーeショップへ進む、購入する、ソフトを更新する、本体の設定を開く、ユーザーを追加する、ソフトやデータを削除する
- A をほかのボタンと同時に押さない。1 つの press の buttons は ["A"] だけにする
