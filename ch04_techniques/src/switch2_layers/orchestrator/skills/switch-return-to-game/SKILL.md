# 遊んでいたソフトへ戻る

## 画面の見た目

HOME 画面は、ソフトの絵が並ぶ本体の画面である。

- 上の左にユーザーのアイコン、上の右に時刻と電池の残りが出る
- 中段にソフトの絵が横に並ぶ。選んでいる絵は水色の枠で囲まれ、絵の上にそのソフトの名前が青い字で出る
- 遊んでいる途中のソフトの絵には、ユーザーのアイコンと「プレイ中」の印が付く
- 「プレイ中」の絵を選んでいるときは、絵の下に「Y ユーザー切替」、右下に「+ オプション」「X ソフトをおわる」「A 決定」が出る (ボタンの名前は丸で囲んで表示される)
- 「プレイ中」でない絵を選んでいるときは、右下は「+ オプション」「A 決定」だけになる
- 下段に丸いアイコンが横に並ぶ。左端は ONLINE で、右のほうに歯車と電源の形のアイコンがある

HOME 画面の上には、次の画面が重なって出ることがある。

- ソフトのオプションの画面: 上にソフトの名前、左に「ソフトの情報」「ソフトの更新」「データ管理」などの項目、右に「ニンテンドーeショップへ」などの項目が並び、右下に「B もどる」「A 決定」が出る
- 確認のダイアログ「プレイ中のソフトを終了します。」: 中央の白い枠の下に、左に「キャンセル」、右に「終了する」のボタンが並ぶ。出たときに選ばれているのは「終了する」

## 操作

手順は 1 回の応答で 1 つだけ進め、操作の後の画面を見てから次の手順に進む。ボタンは 0.12 秒だけ短く押し、押した後は画面が変わるまで待つ。

1. 選んでいる絵に「プレイ中」の印があり、右下に「X ソフトをおわる」が出ていることを確かめる。確かめられたら、A だけを短く押して待つ。HOME 画面が消えて、遊んでいたソフトの画面に戻る

```json
{"actions": [{"type": "press", "buttons": ["A"], "seconds": 0.12}, {"type": "wait", "seconds": 1.0}]}
```

2. 選んでいる絵が「プレイ中」の絵でなければ、「プレイ中」の絵のある向きに十字キーを 1 回だけ押し、選んでいる絵が変わったのを見てから 1 に戻る。次の例は左へ 1 つ動かす

```json
{"actions": [{"type": "press", "buttons": ["LEFT"], "seconds": 0.12}, {"type": "wait", "seconds": 0.5}]}
```

3. ソフトのオプションの画面か、「プレイ中のソフトを終了します。」のダイアログが出ているときは、B を短く押して閉じる。HOME 画面に戻ったら 1 に戻る

```json
{"actions": [{"type": "press", "buttons": ["B"], "seconds": 0.12}, {"type": "wait", "seconds": 1.0}]}
```

4. A を押しても HOME 画面のままのときは、選んでいる絵が「プレイ中」の絵のままかを確かめ直してから、1 をもう一度行う

## してはいけない操作

- オンラインのサービス、ニンテンドーeショップ、購入、本体の設定、ユーザーの追加と削除、ソフトの削除、データの削除の画面に進まない
- 迷ったら何も押さない。次の何もしない JSON で答え、次の画面を待つ

```json
{"actions": []}
```

- 「プレイ中のソフトを終了します。」のダイアログで A を押さない。出たときに選ばれているのは「終了する」で、A を押すと遊んでいたソフトが終わる。このダイアログは B で閉じる
- X (ソフトをおわる) を押さない。遊んでいたソフトが終わる
- Y (ユーザー切替) を押さない
- PLUS と MINUS (オプション) を押さない。オプションの画面には、ソフトの更新・データ管理・ニンテンドーeショップへの項目がある。開いてしまったら B で閉じる
- 「プレイ中」でない絵で A を押さない。別のソフトを起動することになり、遊んでいたソフトを終了する確認のダイアログが出る
- A をほかのボタンと同時に押さない。1 つの press の buttons は ["A"] だけにする
- 下段の丸いアイコンの列に選択を動かさない (DOWN を押さない)。ONLINE をはじめ、本体の機能へ進むアイコンが並ぶ
- この手順では HOME を押さない。ソフトの画面へ戻るのは A で行う
