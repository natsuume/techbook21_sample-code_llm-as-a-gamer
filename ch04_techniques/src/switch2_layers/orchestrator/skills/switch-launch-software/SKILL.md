# 指定されたソフトを起動する

## 画面の見た目

HOME 画面は、ソフトの絵が並ぶ本体の画面である。

- 上の左にユーザーのアイコン、上の右に時刻と電池の残りが出る
- 中段にソフトの絵が横に並ぶ。選んでいる絵は水色の枠で囲まれ、絵の上にそのソフトの名前が青い字で出る。長い名前は途中で切れて表示される
- ソフトをまだ起動していないときは、どの絵にも「プレイ中」の印が無い。右下には「+ オプション」「A 決定」が出る (ボタンの名前は丸で囲んで表示される)
- 起動しているソフトがあるときは、その絵にユーザーのアイコンと「プレイ中」の印が付く
- 下段に丸いアイコンが横に並ぶ。左端は ONLINE で、右のほうに歯車と電源の形のアイコンがある

絵を選んで A を押すと、HOME 画面の下半分に「だれがソフトをあそびますか?」の画面 (ユーザー選択の画面) が重なって出る。ほかのソフトが「プレイ中」のときに別のソフトの絵で A を押すと、先に確認のダイアログ「プレイ中のソフトを終了します。」が出る。このダイアログが出たときに選ばれているのは「終了する」である。

## 操作

手順は 1 回の応答で 1 つだけ進め、操作の後の画面を見てから次の手順に進む。ボタンは 0.12 秒だけ短く押し、押した後は画面が変わるまで待つ。

1. 初期指示に起動するソフトの指定が無いときは、起動しない。次の何もしない JSON で答えて待つ

```json
{"actions": []}
```

2. 指定されたソフトの絵に「プレイ中」の印があるときは、そのソフトは起動している。このスキルの代わりに switch-return-to-game の手順で戻る
3. 選んでいる絵の上に出る名前を読み、初期指示で指定されたソフトの名前と同じかを確かめる。名前が途中で切れているときは、見えている部分が指定と合うかで確かめる
4. 違うときは、十字キーの LEFT か RIGHT を 1 回だけ押す。選んでいる絵と名前が変わったのを見てから 3 に戻る。次の例は右へ 1 つ動かす

```json
{"actions": [{"type": "press", "buttons": ["RIGHT"], "seconds": 0.12}, {"type": "wait", "seconds": 0.5}]}
```

5. 名前が指定と同じなら、A だけを短く押して待つ

```json
{"actions": [{"type": "press", "buttons": ["A"], "seconds": 0.12}, {"type": "wait", "seconds": 1.0}]}
```

6. A を押しても HOME 画面のままのときは、選んでいる絵の名前を確かめ直してから、5 をもう一度行う
7. 「だれがソフトをあそびますか?」の画面が出たら、switch-select-user の手順でユーザーを選ぶ
8. 「プレイ中のソフトを終了します。」のダイアログが出たら、B を短く押して閉じる。その後は起動せず、何もしない JSON で答えて待つ

```json
{"actions": [{"type": "press", "buttons": ["B"], "seconds": 0.12}, {"type": "wait", "seconds": 1.0}]}
```

## してはいけない操作

- オンラインのサービス、ニンテンドーeショップ、購入、本体の設定、ユーザーの追加と削除、ソフトの削除、データの削除の画面に進まない
- 迷ったら何も押さない。次の何もしない JSON で答え、次の画面を待つ

```json
{"actions": []}
```

- 初期指示で指定されたソフトと違うソフトを起動しない。A を押す前に、選んでいる絵の上の名前が指定と同じかを毎回確かめる。名前が指定と合うか分からないときは A を押さない
- 初期指示にソフトの指定が無いときは、どのソフトも起動しない
- 「プレイ中のソフトを終了します。」のダイアログで A を押さない。A を押すと「プレイ中」のソフトが終わる。このダイアログは B で閉じる
- X (ソフトをおわる) と Y (ユーザー切替) を押さない
- PLUS と MINUS (オプション) を押さない。オプションの画面には、ソフトの更新・データ管理・ニンテンドーeショップへの項目がある。開いてしまったら B で閉じる
- A をほかのボタンと同時に押さない。1 つの press の buttons は ["A"] だけにする
- 下段の丸いアイコンの列に選択を動かさない (DOWN を押さない)。ONLINE をはじめ、本体の機能へ進むアイコンが並ぶ
