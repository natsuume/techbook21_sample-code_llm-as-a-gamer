# Switch 2 の操作ルール

このファイルは、コーディングエージェントに Nintendo Switch 2 の実機を操作させるときの指示ファイルの例です。あなたは `switch2-remote` コマンドで画面を撮影し、その画像を読んで、ボタン入力を送ります。

## 前提

- デーモン (`switch2-remote-daemon`) は人が起動します。あなたはデーモンを起動しません。`quit` は、人から終了を指示されたときだけ送ってください
- コマンドはリポジトリーの直下で実行します
- これはオフラインの個人実験です。オンライン対戦や、利用規約で自動操作を禁止しているサービスやゲームは操作しません

## コマンド

```bash
uv run switch2-remote shot /tmp/screen.png 5   # 画面が止まるまで最大 5 秒待って撮影する
uv run switch2-remote tap RIGHT RIGHT A        # ボタンを順に押す
uv run switch2-remote hold A 500               # A を 500 ミリ秒押し続ける
uv run switch2-remote status                   # 動作状況を確かめる
```

- ボタン名: `A` `B` `X` `Y` `L` `R` `ZL` `ZR` `PLUS` `MINUS` `HOME` `UP` `RIGHT` `DOWN` `LEFT` `LR` (`LR` は L と R の同時押し)
- `shot` で保存した PNG は、Read ツールで開いて読みます
- 応答が `error` で始まったら、そのコマンドは失敗しています

## 1 手の進め方

1. `shot` で画面を撮影し、画像を読みます
2. 画面の状態から次の操作を決めます
3. カーソル移動の入力を `tap` で送ります
4. もう一度 `shot` で撮影し、カーソル位置と選択状態を確かめます
5. 狙いどおりの位置にあるときだけ、決定の入力 (A など) を送ります

## 守ること

### 決定操作の前に必ず撮影する

A などの決定操作を送る前に、必ず `shot` で撮影してカーソル位置を確かめてください。カーソル位置を押した回数から決め打ちしてはいけません。選べない項目 (グレー表示) にもカーソルは止まりますし、HOME メニューのソフト一覧では左端で LEFT を押すと右端の「もっとみる」へ回り込みます。

カーソル移動と決定を 1 回の `tap` にまとめるのは、直前の撮影でカーソル位置を確かめ、移動先に誤って決定してはいけない項目が無いと分かっているときだけにしてください。

### カーソル移動に長押しを使わない

カーソル移動は `tap` の短押しで 1 つずつ行ってください。`hold` で十字キーを長押しすると、カーソルが想定より多く進むことがあります (400 ミリ秒の長押しで 3 つ進んだ例があります)。`hold` は、ゲームが長押しを求める操作にだけ使います。

### 通信対戦ソフトを起動しない

HOME メニューには通信対戦のソフトが並んでいることがあります。通信対戦ソフトやオンラインに接続する機能は起動しないでください。ソフトを起動する前には、撮影でカーソルが目的のソフトの上にあることを確かめます。

### 起動直後は無害な入力で反映を確かめる

デーモンの起動直後は、入力が画面に反映されないことがあります。最初の判断を始める前に、決定を伴わない入力 (HOME 画面でのカーソル移動 1 回など) を送り、撮影して反映されたことを確かめてください。反映されていなければ、同じ短押しをもう一度送って確かめます。

### 静止判定を過信しない

`shot` は画面が止まったことだけを確かめるので、画面遷移の途中で止まったフレームを撮ることがあります (メニューを開いた直後の無地の画面、カードを配るアニメーションの途中など)。撮った画像が目的の画面でなければ、数秒待ってから撮り直してください。応答の `settled=False` は、TIMEOUT までに画面が止まらなかったことを示します。

### エラーのときは状態を確かめてから続ける

- `tap` の途中で失敗した応答には、送信済みの入力 (`already sent`) と、届いたかどうか確認できなかった入力 (`unconfirmed`) が含まれます。同じ入力を送り直す前に、撮影して画面の状態を確かめてください
- `status` の `bridge_alive=False` は、入力を送れない状態です。操作を止めて、人にデーモンの再起動を頼んでください
- 撮影した画像にゲームや HOME の画面が映っていない場合は、Switch 2 がスリープしている可能性があります (スリープ中、Elgato 4K X 側は `NO SIGNAL` になります)。Pico 2 W の入力ではスリープを解除できないため、人に本体の復帰を頼んでください

### 終了時は HOME 画面に戻す

Pico 2 W を 1P にしていると、人が手元のコントローラーで HOME に戻れないことがあります。操作を終えるときは、ゲームの終了メニューなどを使ってから `HOME` を送り、撮影で HOME 画面に戻ったことを確かめてください。
